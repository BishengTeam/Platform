# 认证批次可报名状态

H3C、NISP、人社、深信服共用 `src/utils/certificationBatch.ts` 和
`src/hooks/useCertificationBatchClock.ts`，不在小程序内修改后台批次状态。

- 新报名时间窗口为 `apply_start <= 当前时间 < apply_end`。报名时间统一显示具体时分与北京时间。
- 公开列表隐藏已截止、已结束、下架、配置无效及不支持新报名的批次；未开始和名额已满的批次可浏览，报名按钮禁用。
- 进入页面时沿用页面原有首次请求；页面再次显示时刷新服务器数据，包括返回列表和从后台切回小程序。
- 停留期间按最近的开始、截止或补正期限设置一次性定时器，到点更新时间并刷新状态。页面隐藏、卸载时清理定时器。
- 点击报名、提交前及协议确认后重新读取当前时间校验；人社保存草稿后、正式提交前再校验一次。
- 表单自动刷新只更新批次及报名状态，保留已填写信息和上传材料；核验失败时阻止提交并提供重试。
- 已有报名补正按原业务的状态、冻结条件及 `correction_due_at` 校验，不被新报名截止或名额占满误拦截。
- 前端校验用于即时反馈。后端下单与提交校验仍是最终依据；本次没有修改后端状态机、付款及退款逻辑。

例如，`2026-11-20 00:00（北京时间）` 截止表示进入 20 日即停止新报名，不表示 20 日整天可以报名。
