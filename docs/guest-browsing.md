# 游客浏览与登录恢复

首页、认证目录与批次、活动与岗位介绍、题库目录、积分商品、“我的”游客页、协议及关于我们允许匿名浏览。
首页不自动弹登录，游客不展示登录后的海报，不请求个人资料、余额和订单。

## 入口与请求约定

- 页面点击进入个人功能：调用 `navigateWithLogin(target)`。
- 当前公开页面中办理报名或兑换：先 `await requireLogin(target)`，返回 false 时结束本次操作。
- 登录完成只恢复页面，业务提交需要用户再次操作。不要保存操作回调。
- 分享直接进入受保护页面：`AuthGuard` 保存受控目标后回首页，首页展示继续办理入口，不自动打开登录。
- `safeLoginTarget` 只接受明确支持的站内页面、业务 ID 和枚举参数；不保存表单数据或任意返回 URL。
- 返回目标最多保留 30 分钟，成功恢复、取消登录或关闭登录页后清除。报名恢复前重新读取批次状态、时间与名额。

请求默认为 `required`：无登录状态时本地中止；401 保留单次并发刷新能力，失败后清理会话，不弹强制登录窗。
`getPublic` 不发送令牌、不刷新会话；`getOptional` 支持附带登录信息，失效后回退匿名读取。
退出、过期和主动登录会通知挂载的页面；令牌刷新不视为切换账号。公开页面展示个人数据时应丢弃旧会话的迟到响应。

## 后端配套

- H3C 公共批次、人社产品及批次允许匿名读取，人社批次返回公开投影，不包含后台联系人、配置 ID 和模板存储信息。
- 题库列表及目录可以公开读取已发布元数据；题目、答案、进度、练习和权益检查继续鉴权。
- 积分商品允许公开读取；余额、优惠券、兑换及兑换记录继续鉴权。
- 后台无需增加延迟登录配置。本次不部署，Backend 与 Platform 需配套发布。

## 验收

自动测试覆盖匿名接口与受保护接口、并发登录去重、取消返回、批次失效、参数拦截、401 与并发刷新。
微信真机仍需验证：首次启动与下拉刷新、各底部导航游客状态、取消登录返回原浏览位置、微信登录后恢复原批次、分享直达受保护页，以及有效登录用户的报名、兑换和练习流程。
