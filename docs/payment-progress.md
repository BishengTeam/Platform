# 认证交易付款进度页

H3C、NISP、人社、深信服的转账凭证提交、补交、异常申报及零元确认结果统一使用
`pages/payment/result`。人社新报名的零元订单也进入该页，已有报名补正继续返回报名详情。

- 状态与主操作由 `src/utils/paymentProgress.ts` 统一派生，不使用 URL 中的 success、price 等参数判断付款结果。
- 页面先读取订单，再读取银行转账详情；银行详情中的订单状态和应付金额用于更新较早读取的订单快照。
- 待补交显示退回原因、相对期限和北京时间；关闭、退款、异常各有独立说明。
- 主按钮复用订单详情中的付款、凭证查看、补交与异常处理能力。已确认认证订单进入“我的报名”查看审核进度。
- 等待核账时仅在前台每 30 秒刷新；页面重新显示时刷新。提交／补交期限到达时刷新一次。
- 自动请求关闭全局 loading 和网络 toast，失败在页面内提示并保留已加载信息。其他请求维持原有提示行为。
- 同一请求进行期间手动刷新与轮询共用请求；离开页面清理定时器，更换订单或登录会话后丢弃过期响应。
- 课程、题库积分兑换仍使用积分商城的兑换结果，不进入银行付款流程；历史渠道订单仅展示可核实的状态。

该页只读取进度与导航，不直接确认付款、发起退款或发放权益。
