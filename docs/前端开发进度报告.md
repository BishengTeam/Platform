## 六、关键架构决策

1. **报名表单统一化**：`registration/form.tsx`（386行）为统一表单页，根据 `cert.vendor` 动态渲染不同厂商字段。同时保留了三个独立的厂商表单（form-sangfor、form-nisp、form-renshe）用于差异化流程。
2. **实名认证状态流**：贯穿报名流程，使用 `useIdentityCheck` hook 做实名状态检查，在 `personal-info` 页展示三段身份信息（实名/学生/企业）。
3. **AI对话回退机制**：优先调用后端 API，空返回或 mock 回复时回退到本地关键词意图匹配（6种意图规则）。
4. **数据服务已拆分**：5个 service 模块通过 `dataService.ts` barrel 重导出，调用方无需改动。
5. **Mock数据完整**：`src/constants/mock/` 下有 8 个 mock 文件，覆盖首页、认证、竞赛、课程、就业、考试、我的、订单。
