## 四、🟡 服务函数重复/死代码

### 4.1 同一API两次实现

| 函数 | 位置 | 调用的API | 实际使用情况 |
|------|------|-----------|-------------|
| `getCertificationList()` | `zoneService.ts` | `GET /api/cert/certifications` | ✅ 被5+处使用 |
| `getCertifications()` | `userService.ts` | `GET /api/cert/certifications` | ❌ **零引用**，仅定义并导出 |

两个函数返回类型不同但调用完全相同的API。`getCertifications` 在 `userService.ts` 中定义，通过 `dataService.ts` 导出，但**没有任何页面实际调用它**。

### 4.2 代码几乎相同的函数对

| 函数 | 行号 | 代码逻辑 |
|------|------|----------|
| `getMediaUrl(fileId)` | `userService.ts:727` | `baseUrl + '/api/media/' + cleanFileId` |
| `getSystemMediaUrl(mediaId)` | `userService.ts:797` | `baseUrl + '/api/media/' + cleanMediaId` |

两者实现完全相同：去掉参数中的 `/api/media/` 前缀，拼接到 `baseUrl` 后面。区别仅在于参数名（`fileId` vs `mediaId`）和注释。`getSystemMediaUrl` 也**零引用**。

## 五、🟡 工具函数重复

| 函数 | 位置 | 调用情况 |
|------|------|----------|
| `setAuthToken()` | `utils/storage.ts` | ❌ 零引用 |
| `removeAuthToken()` | `utils/storage.ts` | ❌ 零引用 |

与 `request.ts` 中的 `setToken()`/`removeToken()` 功能重叠。`storage.ts` 的 `isLoggedIn()` 依赖 `request.ts` 的 `getToken()`，而 `setAuthToken`/`removeAuthToken` 从未被调用——实际代码都使用 `request.ts` 的版本。

## 六、🟢 代码块重复 — 实名认证状态流

在 `registration/form-sangfor.tsx`、`form-nisp.tsx`、`form-renshe.tsx` 三个文件中，实名认证状态检查代码几乎完全相同（每个文件约60-80行）：

```
if (identity.phase === 'checking') { ... 加载中 ... }
if (identity.phase === 'unverified' || identity.phase === 'submitting') { ... 认证表单 ... }
```

**已存在的解决方案**：`registration/form.tsx`（统一表单）通过 `IdentityCheckGate` 组件封装了这段逻辑。三个独立表单可以复用该组件，消除约180行重复代码。

**注意**：三个独立表单在业务逻辑上有差异（深信服有考试券核销、NISP有拼音转换和模板下载、人社有分支选择器），不应简单合并。但实名认证状态流部分可以统一抽取。

## 八、确认无问题的部分

以下被怀疑可能重复的部分，经检查确认**功能不同，不是重复**：

| 对比 | 差异说明 |
|------|----------|
| `ZoneBanner` vs `ZonesBanner` | ZoneBanner 是通用轮播组件（接收items数组）；ZonesBanner 是专区介绍页静态Banner（使用STRING常量） |
| `ZonesContent` vs `ZonePage` | ZonesContent 是专区导航网格；ZonePage 是通用页面布局容器（Banner+TagFilter+内容区） |
| `form.tsx` vs `form-sangfor/nisp/renshe` | 业务逻辑不同：考试券/拼音/模板/分支选择器/NISP二级区分等。不是简单换皮 |
| `course/index.tsx` vs `training/index.tsx` 课程Tab | course是独立课程列表页，training是Tab页内嵌课程，两者UI结构不同 |
